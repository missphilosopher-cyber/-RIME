METHOD & SCOPE
A clear method.
Explicit boundaries.
ΠRIME is a custom code-language workbench for application-security researchers exploring source obfuscation. Creator generates definitions; Builder formalises existing token rules.
The local Python engine parses a defined subset, preserves token boundaries and layout, restores exact source and compares its AST. Uploaded programs are not executed. Other programming languages and runnable transformed builds require additional implementation.
Repeated aliases, visible layout and access to a decoder can reveal meaning. Custom syntax is not secure encryption. Exported definitions contain original source token spellings; handle them as source-bearing files.
